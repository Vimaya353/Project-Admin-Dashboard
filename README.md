# Admin Dashboard

A responsive admin dashboard built as part of **The Odin Project** curriculum.

The project focuses on using **CSS Grid** to create a dashboard layout and **Flexbox** to arrange smaller components.

## Features

- Dashboard sidebar with navigation
- Search bar and user information
- Header action buttons
- Project cards
- Announcements section
- Trending users section
- Material Design Icons
- Hover effects and basic styling

## Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Material Design Icons

## What I Learned

- Creating layouts with CSS Grid
- Using nested grids
- Combining Grid and Flexbox
- Styling cards and navigation menus
- Using Material Design Icons
- Adding hover effects
- Organizing HTML and CSS code

## Project

This project was created as part of **The Odin Project – Admin Dashboard** assignment.
